# DoubleML Pipeline Output CSV Schema Reference

This document provides a comprehensive reference of all CSV files generated by the `doubleml-pipeline` package during execution. It covers directory paths, generation conditions, column names, data types, and column descriptions.

---

## 1. Output Directory Architecture

The pipeline executes in 4 sequential phases, plus optional optimization and sensitivity analysis. All CSV outputs are organized under the configured `output_dir` (default: `./causal_results`):

```text
<output_dir>/
├── step1_exploration_<treatment_name>/          # Phase 1: Candidate exploration per treatment
│   ├── 1a_full_df_<model_name>.csv             # Row-level dataset with out-of-fold predictions & CIs
│   ├── 1b_geo_item_<model_name>.csv            # Aggregated metrics grouped by Geo and/or Item
│   └── 1c_metrics_<model_name>.csv             # Evaluation metrics and nuisance loss values
│
├── step2_shortlisted_<treatment_name>/          # Phase 2: Shortlisting per treatment
│   └── 2_shortlisted_models_metrics.csv        # Candidate models ranked by composite nuisance error
│
├── step3_final_<treatment_name>/                # Phase 3: Robust ensemble estimation per treatment
│   ├── 3a_iteration_detail.csv                 # Detailed metrics across all n_reps repetitions
│   ├── 3b_iteration_summary.csv                # Summary per candidate model group across repetitions
│   └── best_model/
│       ├── 3c_best_1a_df_<best_model_name>.csv # Row-level dataset with pooled median estimates & CIs
│       ├── 3c_best_1b_geo_item_<best_model_name>.csv # Geo/Item aggregation for the winning model
│       └── best_dml_object_<best_model_name>.pkl     # Serialized DoubleML fitted estimator
│
└── step4_consolidated_results/                 # Phase 4: Multi-treatment consolidation & reporting
    ├── consolidated_1a_full_df.csv             # Master row-level table with all treatments & aggregates
    ├── consolidated_3a_detail.csv              # Concatenated repetition details of winning models
    ├── consolidated_3b_summary.csv             # Winning model summaries across treatments + Total row
    ├── consolidated_3b_summary_geo.csv         # Geo-level consolidated breakdown (if geo_col is set)
    ├── consolidated_3b_summary_item.csv        # Item-level consolidated breakdown (if item_col is set)
    ├── roi_output/<treatment_name>/            # (Generated for non-spend treatments with spend mapping)
    │   ├── 006_updated_prior/
    │   │   └── prior_parameters.csv            # Parametric prior distributions (Normal, LogNormal, Beta)
    │   └── 007_optimization/
    │       └── optimization_metrics.csv        # ROI threshold reallocation simulation
    └── graph/
        ├── 004_cate/
        │   └── cate_coef_dict_pooling.csv      # CATE basis spline coefficients, SEs, and p-values
        ├── 005_prior/
        │   └── prior_parameters.csv            # MMM informative priors for spend treatments
        ├── 006_sensitivity/
        │   └── sensitivity_metrics.csv         # Cinelli-Hazlett (2020) OVB robustness values
        └── 007_optimization/
            └── optimization_metrics.csv        # Spend optimization metrics (when optimize=True)
```

## 2. Overview of Output CSV Files

| # | File Name | Location Pattern | Generation Condition | Purpose |
|---|---|---|---|---|
| 1 | `1a_full_df_<model>.csv` | `step1_exploration_<treatment>/` | `process_log != "lightweight"` | Observation-level nuisance predictions, residuals, and unpooled incremental KPI. |
| 2 | `1b_geo_item_<model>.csv` | `step1_exploration_<treatment>/` | Every exploration run | Sliced performance aggregated by Geo and/or Item dimensions for candidate model. |
| 3 | `1c_metrics_<model>.csv` | `step1_exploration_<treatment>/` | Every exploration run | Single-row evaluation metrics, AutoML nuisance losses ($Y, T$), and ground truth validation. |
| 4 | `2_shortlisted_models_metrics.csv` | `step2_shortlisted_<treatment>/` | Phase 2 completion | Ranked candidates by `combined_error` with `shortlisted` flag for top $N$. |
| 5 | `3a_iteration_detail.csv` | `step3_final_<treatment>/` | Phase 3 completion | All $n_{\text{reps}}$ repetitions for shortlisted models with intra-group normalized losses. |
| 6 | `3b_iteration_summary.csv` | `step3_final_<treatment>/` | Phase 3 completion | Model group summary with mean/SD errors and winning group selection (`best_model = 1`). |
| 7 | `3c_best_1a_df_<model>.csv` | `step3_final_<treatment>/best_model/` | Phase 3 completion | Observation-level dataset using Chernozhukov repeated cross-fitting pooled median and CIs. |
| 8 | `3c_best_1b_geo_item_<model>.csv` | `step3_final_<treatment>/best_model/` | Phase 3 completion | Geo/Item aggregated performance of the winning pooled model. |
| 9 | `consolidated_1a_full_df.csv` | `step4_consolidated_results/` | Phase 4 completion | Master observation-level table combining all treatments, incremental KPIs, portfolio totals, and ROIs. |
| 10 | `consolidated_3a_detail.csv` | `step4_consolidated_results/` | Phase 4 completion | Concatenation of Phase 3 repetition details for winning models across all treatments. |
| 11 | `consolidated_3b_summary.csv` | `step4_consolidated_results/` | Phase 4 completion | Portfolio-level summary across all treatments plus an aggregated `"Total"` row. |
| 12 | `consolidated_3b_summary_geo.csv` | `step4_consolidated_results/` | `geo_col` provided | Geographic slice summary with individual treatment channels and entity totals. |
| 13 | `consolidated_3b_summary_item.csv` | `step4_consolidated_results/` | `item_col` provided | Product/Item slice summary with individual treatment channels and entity totals. |
| 14 | `cate_coef_dict_pooling.csv` | `step4_consolidated_results/graph/004_cate/` | CATE covariates configured | Basis spline regression coefficients, standard errors, and p-values per repetition and pooled. |
| 15 | `prior_parameters.csv` | `graph/005_prior/` or `roi_output/.../006_updated_prior/` | Default | Fitted parametric prior distributions (Normal, LogNormal, Beta) for MMM integration. |
| 16 | `sensitivity_metrics.csv` | `step4_consolidated_results/graph/006_sensitivity/` | `run_sensitivity=True` | Cinelli & Hazlett (2020) Omitted Variable Bias (OVB) robustness values ($RV$) and benchmarks. |
| 17 | `optimization_metrics.csv` | `007_optimization/` | `optimize=True` & single treatment | Simulation of budget cuts on sub-threshold ROI cells and potential reinvestment increase. |

## 3. Detailed File Schemas

### 3.1. Phase 1: Exploration Outputs

#### `1a_full_df_<model_name>.csv`
* **Path**: `step1_exploration_<treatment_name>/1a_full_df_<model_name>.csv`
* **Generated when**: `process_log != "lightweight"` (omitted in lightweight mode to save I/O disk space).
* **Description**: Raw input dataset merged with out-of-fold nuisance predictions, residuals, and single-run treatment effects.

| Column Name | Type | Example | Description |
|---|---|---|---|
| `<input_columns>` | Various | — | All columns from the raw input dataset (e.g. `Date`, `Geo`, `Item`, confounders, treatment). |
| `Y_pred` | `float64` | `10543.21` | Descaled out-of-fold prediction of target outcome $Y$ by the nuisance model $\hat{\ell}(X) = \mathbb{E}[Y \mid X]$. |
| `T_pred` | `float64` | `0.142` | Descaled out-of-fold prediction of treatment $D$ by the nuisance model $\hat{m}(X) = \mathbb{E}[D \mid X]$. |
| `Y_res` | `float64` | `245.8` | Descaled outcome residual: $Y - \hat{Y}_{\text{pred}}$. |
| `T_res` | `float64` | `0.015` | Descaled treatment residual: $D - \hat{T}_{\text{pred}}$. |
| `estimated_incremental_KPI_<d_col>` | `float64` | `1250.40` | Point estimate of incremental KPI attributable to treatment in this exploration run. |
| `estimated_incremental_KPI_<d_col>_2.5%` | `float64` | `980.12` | Lower bound of the 95% confidence interval for incremental KPI. |
| `estimated_incremental_KPI_<d_col>_97.5%` | `float64` | `1520.68` | Upper bound of the 95% confidence interval for incremental KPI. |

### 3.2. Phase 2: Shortlisting Outputs

#### `2_shortlisted_models_metrics.csv`
* **Path**: `step2_shortlisted_<treatment_name>/2_shortlisted_models_metrics.csv`
* **Description**: Aggregates all Phase 1 candidate models for a treatment, normalizes their nuisance RMSEs, computes the composite error, and flags the top $N$ candidates (`shortlisted = 1`).

| Column Name | Type | Example | Description |
|---|---|---|---|
| `<All columns from 1c_metrics>` | Various | — | Inherits all 26 metadata and evaluation metrics from `1c_metrics`. |
| `norm_Y_rmse` | `float64` | `0.125` | Min-max normalized RMSE of Y-nuisance model across all Phase 1 candidates: $\frac{\text{RMSE}_Y - \min + \epsilon}{\max - \min + \epsilon}$. |
| `norm_T_rmse` | `float64` | `0.084` | Min-max normalized RMSE of T-nuisance model across all Phase 1 candidates: $\frac{\text{RMSE}_T - \min + \epsilon}{\max - \min + \epsilon}$. |
| `combined_error` | `float64` | `0.0175` | Primary selection criterion: $\text{norm\_T\_rmse} \times (\text{norm\_T\_rmse} + \text{norm\_Y\_rmse})$. |
| `shortlisted` | `int64` | `1` | Binary flag: `1` if the candidate is within the top $N$ lowest `combined_error`, else `0`. |
| `ML_model_Y` | `string` | `lgbm` | Machine learning algorithm used for outcome nuisance model $\hat{\ell}(X)$. |
| `ML_model_T` | `string` | `xgboost` | Machine learning algorithm used for treatment nuisance model $\hat{m}(X)$. |
| `n_folds` | `int64` | `5` | Number of cross-fitting folds. |

### 3.3. Phase 3: Robust Ensemble Outputs

* **Path**:

| `norm_median_Y_rmse` | `float64` | `0.125` | Min-max normalized median Y RMSE within Phase 3. |
| `raw_T_rmse` | `float64` | `0.185` | Unnormalized T nuisance RMSE for this repetition. |

#### `3c_best_1a_df_<best_model_name>.csv`
* **Path**: `step3_final_<treatment_name>/best_model/3c_best_1a_df_<best_model_name>.csv`
* **Description**: Unit-level dataset for the single winning model group. Treatment point estimates and 95% confidence intervals are aggregated across $n_{\text{reps}}$ repetitions via Chernozhukov et al. (2018) repeated cross-fitting median method.
* **Schema**: Identical column names to `1a_full_df_<model_name>.csv`, but values for `estimated_incremental_KPI_<d_col>`, `_2.5%`, and `_97.5%` reflect robust pooled values:
  $$\tilde{\theta} = \text{median}_b(\hat{\theta}_b), \quad \tilde{\sigma} = \sqrt{\text{median}_b\left( \hat{\text{SE}}_b^2 + (\hat{\theta}_b - \tilde{\theta})^2 \right)}$$

* **Description**: Geo and/or Item aggregated metrics computed directly on the winning model's pooled dataset (`3c_best_1a_df`).
* **Schema**: Identical structure to `1b_geo_item_<model_name>.csv`.
